## Ruang Lingkup Proyek

Perpustakaan Lentera AYP merupakan perpustakaan fiktif yang membutuhkan pengelolaan data untuk mendukung kegiatan pengelolaan anggota, koleksi buku, peminjaman dan pengembalian buku, serta pencatatan aktivitas perpustakaan. Basis data proyek ini akan digunakan untuk menyimpan dan mengelola data secara terstruktur agar proses pengelolaan informasi perpustakaan dapat dilakukan dengan lebih terorganisir.
